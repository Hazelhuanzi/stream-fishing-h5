# 钓鱼小猫 · 溪流小钓手（H5 原型）

第一人称小物钓 + 图鉴收集。当前是 H5 可玩原型：

- 核心循环：抛竿 → 等口 → 抬竿 → 收线 → 图鉴
- 4 种鱼、成就、图鉴、放流记录
- 第一人称：猫爪 + 竹竿 + 鱼线 + 浮漂（猫爪/鱼竿目前是 CSS 占位）
- 陀螺仪测试关：前甩抛竿、上挑抬竿；点按/空格作为 fallback
- 体感设置：开启、校准姿势、灵敏度、反转方向、模拟按钮

## 直接运行

双击 `index.html` 即可；或本地起服务：

```bash
py -m http.server 8123
# 打开 http://127.0.0.1:8123/
```

## 手机测试陀螺仪

- iOS 要求 **HTTPS**，并且必须点「体感 → 开启体感」后允许动作权限。
- 局域网 HTTP 通常开不了体感；需要 HTTPS 部署（Vercel / Netlify / GitHub Pages）或 ngrok。
- 电脑没有陀螺仪，用「体感」面板里的 **模拟抛竿 / 模拟咬钩 / 模拟抬竿**。
- 手感不对时：先点「校准姿势」，再调「灵敏度」；方向反了就勾「反转抛竿方向」。
